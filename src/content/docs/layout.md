稿子写好了，下一步是让它「看起来像那么回事」。排版占推文观感的一半。

:::danger[三条红线]
**正文一律 16 号字。** 标题和正文不要混用字号。

**标题中的「|」必须是英文格式。** 中文「｜」和英文「|」长得像但不一样。

**发表前必须标原创。** 我们的内容不是转载的，一定要勾选原创声明。
:::

## 色彩规范

| 用途 | 颜色名 | HEX 色号 | 预览 |
|---|---|---|---|
| 主色（标题 / 强调） | 生态绿 | `#2E7D32` | <span style="display:inline-block;width:34px;height:16px;border-radius:3px;background:#2E7D32;vertical-align:-3px"></span> |

:::tip[配色原则]
一篇推文最多用 **3 种颜色**：主色 + 辅色 + 灰色系。不要彩虹式排版。
:::

## 排版规则速查卡

| 项目 | 规范 |
|---|---|
| 正文字号 | 16 号 |
| 署名区字号 | 14 号 |
| 署名区对齐 | 居中对齐 |
| 正文缩进 | 首行缩进 |
| 段落间距 | 段前段后各 1 行 |
| 行间距 | 1.75~2.0 倍 |
| 颜色数量 | 不超过 3 种 |
| 标点 | 段落末尾必须有句号 |

## 正确 vs 错误

:::good[正确的排版结构]
- 开头有「点击蓝字，关注 LZU 生灵百态」组件
- 正文用 16 号字，首行缩进
- 框线和底色**穿插使用**，有节奏感
- 段落末尾有句号，标点完整
:::

:::bad[错误的排版结构]
- 从头到尾全用框线，密密麻麻像表格
- 从头到尾全用底色，满屏颜色眼花缭乱
- 混用 14 / 15 / 16 / 18 号字，大小不一
- 段落末尾缺句号，标点缺失
:::

## 署名格式

:::good[正确写法]
```text
图文来源 | 生态学院学生会文娱体育部 张三
图文来源 | 2023级生态学班 李四
编　　辑 | 王五
校　　对 | 赵薇老师
审　　核 | 郭XX老师
```
:::

:::bad[错误写法]
```text
图文来源 | 文体部
编辑/校对/审核 | 王老师
```
问题：不写全部门名称；图文来源和编辑没有分开写。
:::

:::tip[记住一条]
同一篇推文里，图文来源和编辑**永远是分开的两行** —— 哪怕是同一个人干的活。
:::

## 封面图规范

| 项目 | 要求 |
|---|---|
| 尺寸 | 公众号封面 900 × 500px（大图） |
| 安全区 | 重要文字 / logo 放在中间 600 × 300 区域 |
| 字体 | 标题字体不小于 36 号，确保手机端可读 |
| Logo 位置 | 右下角或左下角，不遮挡主体 |
| 背景 | 活动照片优先，纯色次之 |
| 必含元素 | 活动名称 + 学院标识 |
