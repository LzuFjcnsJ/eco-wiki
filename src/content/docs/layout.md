稿子写好了，下一步是让它「看起来像那么回事」。排版占推文观感的一半。

:::info[工具：秀米]
**排版一律在秀米里做**（[xiumi.us](https://xiumi.us)），不用公众号后台自带的编辑器。

原因很简单：引导关注组件、框线、底色、卡片这些小部件都在秀米的组件库里。
统一在一个工具里做，全部门的推文才会长得一致；散着用别的工具拼，风格一定不齐。
:::

:::danger[三条红线]
**正文一律 16 号字。** 标题和正文不要混用字号。

**标题中的「|」必须是英文格式。** 中文「｜」和英文「|」长得像但不一样。

**发表前必须标原创。** 我们的内容不是转载的，一定要勾选原创声明。
:::

## 排版规则速查卡

| 项目 | 规范 |
|---|---|
| 正文字号 | 16 号 |
| 署名区字号 | 14 号 |
| 署名区对齐 | 居中对齐 |
| 正文缩进 | 首行缩进 |
| 段落间距 | 段前段后各 1 行 |
| 行间距 | 1.75~2.0 倍 |
| 颜色数量 | 不超过 3 种 |
| 标点 | 段落末尾必须有句号 |

## 正确 vs 错误

:::good[正确的排版结构]
- 开头有「点击蓝字，关注 LZU 生灵百态」组件
- 正文用 16 号字，首行缩进
- 框线和底色**穿插使用**，有节奏感
- 段落末尾有句号，标点完整
:::

:::bad[错误的排版结构]
- 从头到尾全用框线，密密麻麻像表格
- 从头到尾全用底色，满屏颜色眼花缭乱
- 混用 14 / 15 / 16 / 18 号字，大小不一
- 段落末尾缺句号，标点缺失
:::

## 署名格式

署名区放在正文最末尾，**14 号字、居中**。

### 默认：分开写

```text
图文来源 | 生态学院学生会文娱体育部 张三
图文来源 | 2023级生态学班 李四
编　　辑 | 王五
校　　对 | 赵薇老师
审　　核 | 郭XX老师
```

「图文来源」一行一个人，有几个作者就写几行。

### 例外：图、文、编是同一个人时可以合并

如果**照片和文章编辑是同一个人完成的**，可以并成一行：

```text
图 / 文 / 编 ：张三
```

合并的前提是这三项**本来就只有一个人**。只要图、文、编里出现了第二个人，
就退回上面的分开写法 —— 不能只合并其中两项，那才会真的看不出谁做了什么。

校对和审核不属于这三项，仍然单独写。

:::bad[错误写法]
```text
图文来源 | 文体部
编辑/校对/审核 | 王老师
```
问题：不写全部门名称；把**不同的人**合并成一行。
:::

:::warn[这条规则放宽过（2026-10-02）]
原先写的是「图文来源和编辑**永远是分开的两行**，哪怕是同一个人干的活」。

现在放开合并。回头看这条规则的**目的**：它要防的是
「把不同的几个人混在一行里，看不出谁做了什么」，而不是禁止合并本身。
一个人做的事合起来写，反而更清楚。
:::

## 封面图规范

| 项目 | 要求 |
|---|---|
| 尺寸 | 公众号封面 900 × 500px（大图） |
| 安全区 | 重要文字 / logo 放在中间 600 × 300 区域 |
| 字体 | 标题字体不小于 36 号，确保手机端可读 |
| Logo 位置 | 右下角或左下角，不遮挡主体 |
| 背景 | 活动照片优先，纯色次之 |
| 必含元素 | 活动名称 + 学院标识 |
