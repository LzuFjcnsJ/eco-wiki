## 标准工作流

```text
其他部门举办活动
       │
       ▼
负责人提前联系举办部门 → 安排部员拍照
       │
       ▼
活动结束 → 负责人向举办部门要稿子
       │
       ▼
部员写稿（或从其他部门拿到稿子）
       │
       ▼
【负责人改稿】← 不合格 → 打回重写
       │
       ▼
【郭老师改稿】← 不合格 → 退回修改
       │
       ▼
安排排版（秀米）
       │
       ▼
【负责人 + 团委副书记校对】
       │
       ▼
【郭老师审核排版】← 不合格 → 打回重排
       │
       ▼
郭老师确认 → 发表
```

## 负责人职责清单

- [ ] 校对工作（稿子 + 排版双重检查）
- [ ] 与郭老师对接（改稿意见传达、发表确认）
- [ ] 与其他部门对接（要稿子、安排拍照）
- [ ] 部员有事时顶上（写稿 / 拍照 / 排版都能干）
- [ ] 每月最后一周周六中午 12:00 前，向郭老师邮箱报送当月活动推送原图
      （每个活动一个文件夹，格式：`几月几日推送：推送题目`）

## 跨部门沟通话术

### 要稿子（活动结束后）

> 你好，我是宣传部 XXX。XX 活动已经结束了，想跟你要一下活动的稿子，方便整理推文～最晚**明天晚上**前给我可以吗？

### 催稿（超过 deadline）

> 嗨，打扰啦～上次 XX 活动的稿子还没收到，郭老师那边在催排版了，能不能今天之内给到我？辛苦辛苦！

### 打回重写（稿子不合格）

> 你好，稿子我看了，有几个地方需要修改：
>
> 1. 开头需要加上目的 + 时间 + 地点 + 参与人员
> 2. 领导名字要写全，不能写「XX 老师等」
> 3. 结尾不要写空话，联系一下活动实际内容
>
> 改好之后发给我，我来帮你看看～

### 提醒交材料（对接校团委）

> 校团委那边需要收集 XX 材料，院内截止时间是 **X 月 X 日**，比校团委截止早 X 天，请大家注意时间～

:::tip[话术的通用结构]
先说明「我是谁 + 要什么」，再给「明确的时间点」，最后留一句「辛苦 / 我帮你看看」。催稿尤其不要只发一句「在吗」。
:::

## 文件命名规范

| 类型 | 格式 | 示例 |
|---|---|---|
| 稿子 | `日期_活动名称_稿子.docx` | `0512_生物多样性宣讲_稿子.docx` |
| 照片文件夹 | `日期_推送题目` | `0512_生物多样性宣讲推送` |
| 排版文件 | `日期_活动名称_排版` | `0512_生物多样性宣讲_排版` |
| 海报 | `日期_活动名称_海报.png` | `0512_生物多样性宣讲_海报.png` |

## 例会制度

- **频率**：每半月一次，尽量线下
- **要求**：每人带本子和笔，记录错误和改进点
- **内容**：回顾上半月犯的错误 → 总结改进方法 → 安排下半月工作 → 新人提问

## 紧急情况处理

| 场景 | 处理方式 |
|---|---|
| 负责人联系不上 | 联系另一位负责人 → 仍联系不上则直接联系郭老师 |
| 活动临时通知，来不及拍照 | 先用手机拍，保证有素材，后续补拍 |
| 稿子迟迟交不上来 | 向郭老师汇报，由老师出面协调 |
| 相机故障 | 立即联系院办，看是否有备用机 |
| 公众号后台异常 | 截图保存，联系郭老师，暂停发表 |

## 其他注意事项

1. **不清楚就问** —— 一知半解去干活 = 浪费时间 + 效果差。
2. **部员请假** —— 既要告知会议负责人，也要告知部门负责人。
3. **开会前** —— 部门负责人需确认部员是否全部到场。
4. **组织部每月** —— 有一篇团日活动稿子，负责人要记得及时联系。
5. **校运会 / 院运会** —— 稿件由宣传部写，不是文娱体育部。
6. **部门全称** —— 写「生态学院学生会文娱体育部」，不能写成「文体部」。
