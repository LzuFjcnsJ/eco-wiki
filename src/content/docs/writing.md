写稿是整个宣传工作的起点。一篇好稿子 = **格式规范 + 内容扎实 + 不抄**。

:::danger[红线规则]
严禁抄袭。发现抄以前的稿子，直接打回重写，没有商量的余地。
:::

## 写作模板（填空式）

直接复制这个结构，往里填内容即可。

```text
【开头】
为（目的，一两句话），我院于（几月几日）（上午/下午/晚上）
在（具体教室）开展了（活动名称）。（领导职务+姓名）、（老师职务+姓名）
及（参与人员描述）参加了本次活动。

【正文】
第一部分：……
（谁做了什么，讲了什么内容）

第二部分：……
（谁做了什么，讲了什么内容）

【结尾】
（联系实际的感悟，不写空话）
```

## 开头四要素

| 要素 | 要求 | 常见错误 |
|---|---|---|
| 目的 | 一两句话带过 | 展开变成背景介绍 |
| 时间 | 只写「几月几日 + 上午/下午/晚上」 | 写成「5月12日下午2:30」 |
| 地点 | 精确到教室号，如天山堂A201 | 只写「在学院」 |
| 参与人员 | 按职位从大到小：领导 → 老师 → 同学 | 写「XX老师等」偷懒省略 |

:::good[正确写法]
为增强同学们对生态保护的认识，我院于 5 月 12 日下午在榆中校区天山堂 A201 开展了「生物多样性日」主题宣讲活动。学院党委副书记王老师、团委书记李老师及 2023 级全体本科生参加了本次活动。
:::

:::bad[错误写法]
为了响应国家号召，贯彻落实习近平生态文明思想，进一步加强我院学生的环保意识……（太长，像背景介绍）

5 月 12 日下午 2:30 在 A201 举办了活动。（没写参与人员）
:::

## 正文写作要点

- 按**活动流程的自然分段**来写，不要按时间记流水账。
- 每个人讲了什么、做了什么，**写清楚名字 + 内容**。
- 如果有多位领导讲话，按**职位从高到低**的顺序写。

## 结尾写法

写活动意义，联系当下实际。

:::good[正确写法]
通过亲手制作昆虫标本，同学们直观了解了昆虫分类学的基本方法，不少同学表示这是第一次近距离观察标本制作全过程。
:::

:::bad[错误写法]
本次活动圆满成功，取得了良好的效果，增强了同学们的环保意识。（假大空）
:::

## 最常见的三个错误

1. **领导名字写不全** —— 出现「XX 老师等」就是不行的，每个人的名字都要列出来。
2. **时间写了具体几点** —— 只写「上午 / 下午 / 晚上」，不写 14:30。
3. **职位第一次出现没写全** —— 「郭老师」第一次出现必须写「团委书记郭 XX 老师」。

:::tip[省事儿的做法]
拿不准的时候，先把「目的 / 时间 / 地点 / 人员」四行单独列出来核对一遍，再连成一段。比写完整段再回头挑错快得多。
:::

## 交稿清单

- [ ] 开头四要素齐全（目的 / 时间 / 地点 / 参与人员）
- [ ] 所有领导和老师姓名列全，无「等」字省略
- [ ] 人名首次出现写清写全职位
- [ ] 地点精确到教室号
- [ ] 不写年份，不写具体几点
- [ ] 正文按活动环节分段，非流水账
- [ ] 结尾联系活动实际，无空话套话
- [ ] 通读一遍，确认没有从别处抄来的句子
