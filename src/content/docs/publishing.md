**郭老师未同意，绝对不能发表。** 无论多急，必须提前沟通确认。

**转载必须加原文链接。** 少了这条就是侵权。
:::

## 发表流程

```text
写稿 → 负责人改稿 → 郭老师改稿
    → 安排排版 → 负责人 + 团委副书记校对
    → 郭老师审核排版 → 确认无误 → 发表
                      ↘ 有问题 → 打回修改 → 重新校对
```

:::tip[关键节点]
郭老师审核通过后，还要**单独确认发表时间**。不要审核完就立刻点发送。
:::

## 发表前检查清单

### 原创推文

- [ ] 已标**原创声明**（公众号后台勾选）
- [ ] 标题前**没有**多余的「转载|」前缀
- [ ] 作者署名正确（写我们自己的部门 / 姓名）
- [ ] 专栏分类已选择
- [ ] 封面图已上传且预览正常
- [ ] 图文来源 / 编辑 / 校对 / 审核署名完整
- [ ] 图 / 文 / 编 为同一人时，已按「图 / 文 / 编 ：xx」合并署名（有第二个人则分开写，见「排版设计 · 署名格式」）
- [ ] 郭老师已确认可以发

### 转载推文

- [ ] 标题前加 **「转载|」**（「|」必须是英文格式）
- [ ] 作者写**原作者名字**（如「青春兰大」）
- [ ] **已加原文链接**（后台「原文链接」栏粘贴）
- [ ] 图文来源写原出处（不止一个就都写）
- [ ] 编辑 / 校对 / 审核署名完整
- [ ] 内容已删除无关信息
- [ ] 郭老师已确认可以发

## 发布时间建议

| 场景 | 建议时间 | 理由 |
|---|---|---|
| 活动当天推文 | 当晚 20:00~22:00 | 趁热度，但别太晚 |
| 次日补发 | 早上 9:00~10:00 | 通勤时间阅读高峰 |
| 重要通知 | 上午 10:00 前 | 给人留出反应时间 |
| 周末 / 节假日 | 上午 10:00~11:00 | 大家刷手机的高峰 |
| 紧急转载 | 收到后 2 小时内 | 时效性优先 |

:::warn[以郭老师为准]
上表只是参考区间，具体时间以郭老师确认为准。
:::

## 该不该转载

不是校团委每一条通知都要转载。参考以下优先级：

| 优先级 | 类型 | 是否转载 |
|---|---|---|
| ★★★ | 全院师生必须知晓的通知 | 必须转 |
| ★★☆ | 与生态学院相关的活动 / 成果 | 建议转 |
| ★☆☆ | 全校性通用通知 | 视情况 |
| ☆☆☆ | 与其他学院强相关、与我院无关 | 不转 |

## 出错补救

### 小错误（错别字、标点）

1. 立即联系郭老师说明情况
2. 在公众号后台**修改文章**（每篇可改 20 个字以内）
3. 修改后截图发给郭老师确认

### 大错误（信息错误、图片错）

1. **立即删除该推文**（后台操作）
2. 联系郭老师说明情况
3. 修正后重新发表（标题加「更正版」或更新日期）
4. 如已在群内转发，需在群内说明更正

### 漏标原创声明

1. 立即删除（超过 24 小时无法补标原创）
2. 重新发表并勾选原创声明

:::warn[发表前一定要预览]
手机扫码预览，不要只看电脑端。重点检查：封面图是否裁切正常、文字有无溢出、图片是否加载。
:::
