## FAQ 常见问题

### 推文开头不知道怎么写怎么办？

看「撰写文稿」章节的**写作模板**，直接填空就行。目的一两句话带过，然后写时间、地点、参与人员。

### 相机参数调不好，拍出来很暗怎么办？

先确认 ISO 是否够高（室内至少 800），快门不低于 1/60s。如果还是暗，后期用修图软件调亮。实在不行，换一个光线好的位置拍。

### 秀米里怎么插入「点击蓝字关注」组件？

在秀米模板库搜索「关注引导」或「引导关注」，选择适合的组件拖入即可。

### 转载文章时原作者不同意怎么办？

不要转载。告知郭老师情况，改为**自行撰写简讯**或**仅转发链接**到群内。

### 发表后发现错别字能改吗？

可以。公众号后台每篇推文可修改 **20 个字以内**。超过 20 字或图片错误，需要删除重发。

### 活动照片拍了但全糊了怎么办？

先看有没有一两张勉强能用的。如果没有，联系举办部门看他们有没有手机照片可以补充，同时向郭老师说明情况。

### 其他部门一直不交稿子怎么办？

第一次友好提醒，第二次正式催稿（抄送郭老师），第三次由郭老师出面协调。不要自己硬扛。

### 排版时颜色怎么选？

看「排版设计」章节的**色彩规范**，主色用生态绿 `#2E7D32`，最多搭配 2 种辅助色。不要一篇推文出现 5 种以上颜色。

### 推文什么时候发最好？

一般活动当天晚上 20:00~22:00，或次日早上 9:00~10:00。具体以郭老师确认为准。

### 我是新成员，应该从哪里开始学？

按这个顺序：**写稿 → 拍摄 → 排版 → 发表 → 设计工具 → 协作流程**。前三章是核心技能，后三章是规范和流程。也可以直接看「新人第一周」。

## 术语表

| 术语 | 解释 |
|---|---|
| 秀米 | 微信公众号图文排版工具（xiumi.us），用来做推文排版 |
| 可画 / Canva | 在线设计工具（canva.cn），用来做海报和封面图 |
| 原创声明 | 公众号功能，标明内容为原创，别人转载需授权。我们的内容必须标 |
| 原文链接 | 转载推文中必须填写的字段，指向原文出处 |
| 转载\| | 转载推文标题前缀，「\|」必须是英文格式 |
| 图文来源 | 推文末尾署名，标明照片和文字来自谁 |
| 校对 | 发表前检查排版和内容是否正确，目前由赵薇老师负责 |
| 审核 | 最终把关，由郭老师负责，未通过不能发表 |
| 团委副书记 | 负责宣传工作的学生干部，参与校对环节 |
| 院办 | 学院办公室，相机借还的地方 |
| LZU 生灵百态 | 生态学院官方公众号名称 |
| HEX 色号 | 颜色的十六进制编码，如 `#2E7D32` 代表生态绿 |
| 首行缩进 | 段落第一行空两格，正文排版统一要求 |
| 封面图 | 推文在公众号列表里显示的配图，900 × 500px |
