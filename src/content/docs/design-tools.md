## 主推工具：可画（Canva）

推荐理由：上手快、模板多、协作方便。支持网页版和 APP。

- 官网：[www.canva.cn](https://www.canva.cn)
- APP 搜索「可画」下载
- 支持中文界面，有免费版和 Pro 版

## 常用尺寸速查

| 用途 | 尺寸（px） | 比例 |
|---|---|---|
| 公众号封面图（大图） | 900 × 500 | 16:9 |
| 公众号封面图（小图） | 200 × 200 | 1:1 |
| 活动海报（竖版） | 1080 × 1920 | 9:16 |
| 活动海报（横版） | 1920 × 1080 | 16:9 |
| 招新海报 | 1080 × 1920 | 9:16 |
| 朋友圈配图 | 1080 × 1080 | 1:1 |
| 展板 / 易拉宝 | 800 × 2000 | 4:10 |

## 配色参考（生态学院风格）

| 场景 | 推荐配色 | 色号 |
|---|---|---|
| 正式活动海报 | 深绿 + 白 + 金 | `#1B5E20` / `#FFFFFF` / `#FFD700` |
| 日常推文封面 | 生态绿 + 浅灰 | `#2E7D32` / `#F5F5F5` |
| 节日 / 趣味活动 | 渐变绿 + 白色文字 | `#43A047` → `#66BB6A` |
| 警示 / 通知 | 红色 + 白 | `#D32F2F` / `#FFFFFF` |

:::tip[最多三种色]
一篇设计最多用 3 种颜色，保持统一感。
:::

## 海报制作清单

- [ ] 确定用途（活动宣传 / 节日祝福 / 招新 / 通知）
- [ ] 选对尺寸（参考上方尺寸表）
- [ ] 在可画中搜索对应模板（关键词：活动海报 / 学术讲座）
- [ ] 替换文字内容（标题 + 时间 + 地点 + 主办方）
- [ ] 替换背景图（优先用活动相关照片）
- [ ] 检查学院 logo 是否放置（右下角）
- [ ] 检查文字是否超出安全区（手机端能看清）
- [ ] 导出为 PNG（高清）或 JPG（文件小）

## 封面图制作规范

| 项目 | 要求 |
|---|---|
| 尺寸 | 900 × 500px |
| 安全区 | 中间 600 × 300px 放重要文字 |
| 标题字号 | 不小于 36 号 |
| Logo | 右下角或左下角 |
| 背景 | 活动照片 > 纯色渐变 > 纹理 |
| 导出格式 | PNG（高清）/ JPG（小文件） |

## 模板资源

- **可画模板库**：搜索「学术讲座」「校园活动」「环保主题」
- **学院历史推文**：参考之前发过的同类型活动封面
- **校团委推文**：参考其视觉风格

:::tip[先抄版式，再加风格]
第一次做某类设计时，先照着优秀案例的版式来，熟练之后再加入自己的风格。
:::
