这篇是给**刚进部门的你**准备的。不用一次看完所有章节，按天来就行。

:::tip[先记住一句话]
宣传部的活是流水线：**谁办活动 → 谁给素材 → 谁写稿 → 谁排版 → 谁审核**。你要做的是把自己那一环做扎实。
:::

## 第 1 天 · 读规矩

把这三篇通读一遍，不求记住，只求知道「有这么回事、在哪里查」。

- [ ] [撰写文稿](/wiki/writing/) —— 开头四要素是重点
- [ ] [相机拍摄](/wiki/photography/) —— 知道相机在院办借
- [ ] [排版设计](/wiki/layout/) —— 知道正文一律 16 号字

## 第 2 天 · 摸设备

- [ ] 跟负责人去院办走一趟借还流程
- [ ] 亲手装一次电池、摘镜头盖、开机
- [ ] 把[参数速查表](/wiki/photography/#参数速查表)抄在手机备忘录里
- [ ] 练习：在会议室里拍 5 张「讲话人抬头看观众」的特写

:::warn[这一天最重要的不是拍好]
是**把相机带子挂在脖子上**，形成肌肉记忆。摔机是重大事故，其他失误都还能补救。
:::

## 第 3 天 · 跟一次活动

- [ ] 跟着去现场，只做一件事：按[拍摄清单](/wiki/photography/#拍摄清单)逐条打勾
- [ ] 回来导出照片，按 `日期_活动名称_序号.jpg` 命名
- [ ] 感受一下「每组多拍 3~5 张」到底能救回多少张废片

## 第 4 天 · 写第一篇稿

- [ ] 找一篇往期推文当参照，照着[写作模板](/wiki/writing/#写作模板填空式)填一份
- [ ] 核对[交稿清单](/wiki/writing/#交稿清单)的每一项
- [ ] 交给负责人改，重点看他改了什么

:::danger[唯一不能碰的线]
**严禁抄袭。** 可以照格式，但内容必须是这次活动真实发生的。抄了直接打回重写。
:::

## 第 5 天 · 学排版

- [ ] 在秀米里把第 4 天的稿子排一遍
- [ ] 对照[排版规则速查卡](/wiki/layout/#排版规则速查卡)逐项检查
- [ ] 自己动手做一张 900 × 500 的封面图

## 第 6 天 · 了解发布

- [ ] 读一遍[发表与发布规范](/wiki/publishing/)
- [ ] 记住这条铁律：**郭老师没同意，不能发表**
- [ ] 知道原创和转载的差别，以及为什么转载必须加原文链接

## 第 7 天 · 复盘

- [ ] 回答自己三个问题：哪一步最慢？哪一步最容易出错？下周想重点练什么？
- [ ] 带着答案去参加下一次[例会](/wiki/collaboration/#例会制度)
