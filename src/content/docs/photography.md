活动照片是推文的灵魂，拍不好后面全白搭。这一章覆盖从院办借机到归还的每一步。

:::danger[两条红线]
**相机带子必须挂在脖子上。** 手没拿稳摔了相机是重大事故。

**每组照片必须多拍几张。** 至少保证有一张所有人都睁眼、表情到位。
:::

## 拍摄清单

### 活动前

- [ ] 提前去院办借相机，登记时间和用途
- [ ] 安装电池，确认电量充足
- [ ] 摘下镜头盖，打开开关
- [ ] 提前调整参数（参考下方参数速查表）
- [ ] 相机带子挂在脖子上
- [ ] 到达活动现场，踩点确认拍摄位置

### 活动中

- [ ] 拍主持人 + PPT 封面（全景）
- [ ] 拍主持人特写
- [ ] 拍每位讲话人的特写（**抬头看观众**的角度最优）
- [ ] 从后往前拍全场（展示人数和氛围）
- [ ] 从前往后拍全场（展示屏幕内容）
- [ ] 参与人少时，结束时组织大合照（第一排手持横幅 / 旗帜）
- [ ] 每组镜头多拍 3~5 张（防闭眼 / 表情崩）

### 活动后

- [ ] 固定位置导出照片（手机直连或读卡器）
- [ ] 导出过程中不要移动位置（防止漏导）
- [ ] 检查照片数量是否齐全
- [ ] 光线暗的照片适当调亮，保证可用
- [ ] 查看电量，不足时放助理桌上充电并告知郭老师
- [ ] 关闭开关 → 翻转显示屏 → 扣上镜头盖 → 收入相机包
- [ ] 归还院办，登记归还时间

## 参数速查表

| 场景 | ISO | 快门速度 | 光圈 | 备注 |
|---|---|---|---|---|
| 室内会议（灯光充足） | 400~800 | 1/60s | f/3.5~5.6 | 避免低于 1/60，防手抖 |
| 室内会议（灯光昏暗） | 1600~3200 | 1/60s | f/2.8~3.5 | 噪点会多，后期适当降噪 |
| 室外白天 | 100~200 | 1/125s~1/250s | f/5.6~8 | 光线好，随便拍都清晰 |
| 夜间活动 | 1600~6400 | 1/30s~1/60s | f/2.8 | 尽量靠三脚架或稳定支撑 |
| 大合照 | 200~400 | 1/125s | f/8~11 | 小光圈保证前后排都清晰 |

:::tip[新手建议]
不确定就先拍一张看效果，再微调。不要怕多拍 —— 存储卡很便宜，废片可以删，漏拍没法补。
:::

## 废片图鉴

| 废片类型 | 原因 | 怎么避免 |
|---|---|---|
| 拍糊了 | 快门太慢 / 手抖 | 快门不低于 1/60s，双手持机 |
| 过曝（一片白） | ISO 太高 / 对着强光灯拍 | 避开直射灯光，降低曝光补偿 |
| 闭眼 / 表情崩 | 只拍了一张 | 每组连拍 3~5 张，回来挑 |
| 构图歪斜 | 没看取景器水平线 | 拍照前先确认画面横平竖直 |
| 背景杂乱 | 没注意镜头里有什么 | 拍之前扫一眼背景，避开垃圾桶、杂物 |
| 只有后脑勺 | 只拍了 PPT / 屏幕 | 讲话人特写必须从侧面或正面拍 |

## 好照片标准

- [ ] 主体清晰，不模糊
- [ ] 曝光正常，不过亮也不过暗
- [ ] 人物眼睛睁开，表情自然
- [ ] 构图横平竖直
- [ ] 背景干净，没有干扰元素
- [ ] 能看清 PPT 上的文字（如果需要拍 PPT）

## 照片命名规范

导出的照片按以下格式命名，方便后期查找：

```text
日期_活动名称_序号.jpg
例：0512_生物多样性宣讲_01.jpg
```

合照单独标记：

```text
日期_活动名称_大合照.jpg
例：0512_生物多样性宣讲_大合照.jpg
```
