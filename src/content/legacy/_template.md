文件名以 `_` 开头的都不会被收录，所以这份模板可以一直留在这个目录里。

复制一份，改个名字（比如 `2027-wangwu.md`），把上面的字段填上，档案页就会自动多出一条。

**正文可以留空**，只有 front-matter 里那句话也能成立 —— 但如果你愿意多写几句当时的处境、具体的教训，这条档案会更有价值。

字段说明：

| 字段 | 说明 |
|---|---|
| `name` | 姓名 |
| `role` | 职务全称，如「宣传部负责人」「排版组组长」 |
| `cohort` | 届别，如「2027 届」 |
| `year` | 年份，决定排序（数字，越大越靠前） |
| `lesson` | 一句话。会作为这条档案的标题显示 |
| `stage` | `in-office` 在任 / `alumni` 已毕业 |
| `placeholder` | 内容还没补全时设为 `true`，页面上会显示「待补充」标记 |
